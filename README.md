# ДолжничОК — макет интерфейса

Учебный прототип интерфейса сервиса для студентов и преподавателей. Это только фронтенд: страницы показывают примерные сценарии, но не обращаются к серверному API и не сохраняют данные.

## Как открыть макет

Откройте PowerShell в папке проекта и выполните команду:

    dotnet run --project DolzhnikOk.csproj

Откройте адрес, напечатанный в терминале. Остановить приложение можно сочетанием Ctrl+C.

Если команда dotnet не находит .NET 10 в уже открытом окне PowerShell, откройте новое окно или выполните:

    $env:DOTNET_ROOT = 'C:\Users\danil\Documents\Codex\.dotnet'
    $env:PATH = "$env:DOTNET_ROOT;$env:PATH"
    dotnet run --project DolzhnikOk.csproj

## Запуск в Visual Studio 2026

Откройте файл DolzhnikOk.slnx. В решении находится единственный проект DolzhnikOk, поэтому он будет запускаться как стартовый. Нажмите F5 для запуска с отладкой или Ctrl+F5 без отладки.

## Три экрана

- / — окно входа. Переключатель роли меняет назначение кнопки входа. Кнопка входа ведёт на экран выбранной роли, а «Зайти гостем» открывает список студента. Пароли не проверяются.
- /prepodavatel — форма создания отработки. Поля проверяются в браузере: обязательность, число мест, дата и порядок времени. После нажатия показывается подтверждение, но отработка нигде не создаётся и не сохраняется.
- /student — список примерных отработок. Поиск, фильтры и сортировка действуют на демонстрационные данные в памяти страницы. Кнопка «Записаться» меняет состояние карточки до перезагрузки страницы.

## Где менять макет

- Components/Pages/Home.razor — экран входа.
- Components/Pages/Teacher.razor — экран преподавателя и правила проверки полей.
- Components/Pages/Student.razor — экран студента, примеры карточек, поиск, фильтры и сортировка.
- Components/Layout/BlankLayout.razor — пустая рамка, которая используется для экрана входа.
- Components/Layout/MainLayout.razor — общая шапка и подвал экранов преподавателя и студента.
- Components/Layout/NavMenu.razor — логотип и ссылки между экранами.
- Components/App.razor — основной HTML-документ. Здесь задан русский язык и подключён CSS.
- Components/Routes.razor — сопоставляет адреса страницам.
- Components/_Imports.razor — общие подключения Razor-компонентов.
- wwwroot/app.css — оформление и адаптация для небольших экранов.
- Program.cs — запускает веб-приложение и включает серверную интерактивность Blazor. Здесь пока нет бизнес-логики, базы данных или API.
- DolzhnikOk.slnx — решение Visual Studio, в которое включён проект.
- DolzhnikOk.csproj и global.json — настройки проекта и версии .NET.

## Как устроены интерактивные элементы

В файлах .razor рядом с HTML-разметкой находится блок @code с кодом C#. Например, на экране студента в блоке @code лежат демонстрационные карточки и методы поиска/переключения кнопки записи. Это нужно только для показа поведения интерфейса; при перезапуске или обновлении страницы изменения исчезают.

На экране входа поля переключают маршрут между двумя страницами, а не выполняют настоящую авторизацию. В форме преподавателя сообщение об успешном заполнении тоже является только демонстрацией.
